# はじめに

ローカル LLM を試し始めた当初、筆者の関心は「自分の PC でモデルが動くか」にありました。ところが、扱うモデルを大きくし、GPU を増やし、コード生成や動画生成へ用途を広げると、問いはすぐに変わりました。必要な VRAM はどのくらいか。システムメモリや PCIe の帯域は足りるか。Windows と Radeon の組み合わせで、どのソフトウェアなら安定して動くか。更新の速い ROCm とアプリケーションを、どうすれば壊さずに保守できるか。このような判断の積み重ねが、ローカル LLM 環境そのものです。

本書は、筆者が公開してきたブログ記事と GitHub リポジトリをもとに、Windows と自作 PC を使った検証過程を一冊の流れへ再編集したものです。個人向けの検証機を設計し、OCuLink で GPU を増設し、Windows 向け llama.cpp をビルドします。その推論サーバーを Xcode から利用し、さらに ComfyUI と MiniMax H3 による動画生成へ広げます。最後に、ROCm 10 への更新で遭遇した互換性問題と、環境を継続的に運用するための切り分け方を整理します。

Radeon を選べば、同じ VRAM 容量の NVIDIA GPU より手頃な構成を作れる場合があります。一方で、生成 AI のソフトウェアは CUDA を前提にしているものが多く、追加の調査や調整が必要です。本書ではこの手間を隠しません。うまく動いたコマンドだけでなく、なぜその組み合わせを選んだか、どこで失敗したか、何を安定性のために諦めたかも記します。

記載内容は、特に断りがない限り 2026 年 8 月 31 日時点の検証結果です。モデル、ドライバー、ROCm、PyTorch、llama.cpp、ComfyUI は短期間で変化します。実際に試すときは、本書の手順を固定的な正解として扱わず、リンク先の公式情報と各リポジトリの最新版も確認してください。
